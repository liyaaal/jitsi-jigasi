# Meeting Pro v1.0

Профессиональное расширение для Chrome и инструмент автоматизации для Jitsi Meet. Обеспечивает высококачественную запись встреч, разделение участников по ролям и интеллектуальную генерацию протоколов.

## Основные компоненты:
1.  **Chrome Extension (Meeting Pro)**: Удобный интерфейс для записи прямо в браузере.
2.  **Node.js Bot**: Инструмент для автоматического подключения и записи встреч через Playwright.
3.  **AI Engine**: Интеграция с OpenAI/Groq для транскрипции (Whisper) и анализа текста (Llama/GPT).

### 🔌 Plug-and-Play (Уже настроено)
Расширение поставляется с **предустановленными ключами Groq**. Заказчику не нужно ничего настраивать — просто установил и нажал «Начать запись». Все работает «из коробки» на полной скорости!

## Возможности:
- **Авто-конфигурация**: Ключи и URL уже вшиты в код как стандартные настройки.
- **Разделение спикеров**: Каждый участник записывается в отдельный поток, что исключает ошибки в расшифровке.
- **Интеллектуальный Recap**: Система исправляет опечатки, пунктуацию и создает краткое содержание беседы.
- **Поддержка Groq**: Молниеносная и бесплатная (на текущем этапе) обработка данных.
- **Оффлайн-режим**: Возможность скачивания исходных аудиофайлов (.webm) для ручной проверки.

## Быстрый старт (Расширение):
1. Перейдите в `chrome://extensions/`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `jitsi-ai-extension`.
4. Введите API ключ в настройках расширения и начните работу.

## Настройка AI-провайдера:
- **OpenAI (По умолчанию)**: Классический вариант.
- **Groq (Бесплатно/Быстро)**: 
  - API Base URL: `https://api.groq.com/openai/v1`
  - Используйте ключ формата `gsk_...`

## Командная строка (Bot):
```bash
npm install
node bot.js "https://meet.jit.si/YourRoomName"
```

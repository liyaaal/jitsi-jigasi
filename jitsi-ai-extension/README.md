# Расширение Meeting Pro

Выберите эту папку через **Режим разработчика → Загрузить распакованное расширение** на странице `chrome://extensions` или `edge://extensions`.

Значок расширения открывает отдельную вкладку. Выберите звук вкладки, системный звук или микрофон, проверьте индикаторы и начните запись. API-ключ нужен только для расшифровки. Вкладку управления держите открытой во время записи.

Подробности, ограничения, хранение данных и работа с приложениями описаны в [основной инструкции](../README.md).

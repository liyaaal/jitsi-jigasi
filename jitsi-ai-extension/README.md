# Jitsi AI Регистратор v1.2

Профессиональное расширение для Chrome, которое записывает встречи в Jitsi Meet, транскрибирует речь участников и создает умный протокол встречи с помощью ИИ.
### 🚀 Работа через Groq (БЕСПЛАТНО)
Если на OpenAI нет баланса, используйте **Groq**:
1. Получите бесплатный ключ на [console.groq.com](https://console.groq.com/keys).
2. В расширении откройте «Дополнительные настройки».
3. В поле **API Base URL** вставьте: `https://api.groq.com/openai/v1`
4. Вставьте ключ от Groq и пользуйтесь! Это в 10 раз быстрее и сейчас бесплатно.
## Основные возможности:
- **Разделение по ролям**: Каждый участник записывается отдельно, что гарантирует 100% точность того, кто что сказал.
- **Имя каждого участника**: Автоматическое определение ников прямо из Jitsi.
- **Захват вашего голоса**: Записывает и вас, и собеседников.
- **ИИ-Корректор**: GPT-4 исправляет ошибки распознавания и опечатки перед созданием отчета.
- **Умный пересказ**: Выделение ключевых тем и списка задач (Action Items).
- **Экспорт**: Возможность скачать готовый отчет в формате .txt.

## Инструкция по установке:
1. Перейдите по адресу `chrome://extensions/`.
2. Включите **"Режим разработчика"** (Developer mode) в правом верхнем углу.
3. Нажмите кнопку **"Загрузить распакованное расширение"** (Load unpacked).
4. Выберите папку `jitsi-ai-extension`.

## Как использовать:
1. Откройте любую встречу на `meet.jit.si`.
2. **Важно**: Обновите страницу (F5) после установки расширения.
3. Откройте расширение на панели инструментов Chrome (рекомендуется "закрепить" его булавкой).
4. Введите ваш **OpenAI API Key**.
5. Нажмите **"Начать запись"**.
6. По окончании встречи нажмите **"Остановить и Сохранить"**.
7. Подождите завершения обработки и скачайте результат.
